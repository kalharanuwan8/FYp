# Simulated data — NOT measurements

Files in this folder are generated by `evaluation/thesis_numbers/generate_simulated_selftest.py`
to exercise the metrics pipeline. They contain no camera data and no real participant, and
every row is marked `measured=false`.

Do not report them as results or put them in the same table as the live self-test runs
(`raw/live_webcam_selftest_*.csv`).
